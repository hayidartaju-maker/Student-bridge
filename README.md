# Boarding Bridge

Boarding Bridge is a Flutter application for school and boarding management.

## Overview

This project manages:
- student registration
- parent records
- student results
- CSV result imports
- role-based user flows
- portal-style dashboard experience

## Roles

- Admin
- Teacher
- Parent
- Student

## Features

- Student registration with photo upload
- Parent information collection
- Results upload via CSV
- Student results dashboard
- Theme support
- Session persistence
- Role selection screen

## Tech Stack

- Flutter
- Dart
- Provider
- Supabase
- Image Picker
- File Picker
- CSV parsing

## Getting Started

1. Install Flutter
2. Run:
   flutter pub get
3. Start the app:
   flutter run

## Notes

This project is designed to connect to Supabase and store real data in the backend.
